# User Guide – Mini Carivix

## 1. Introduction

This guide explains how end users can access and use the Mini Carivix platform to obtain business insights using voice or text queries.  
It is intended for users with no technical background.

---

## 2. Accessing the Platform

Mini Carivix is available as a web-based application.

- Frontend Application URL:  
  https://carivix-frontend-42js4guaza-uc.a.run.app

A modern web browser is required for optimal usage.
![HOMESCREEN](https://i.postimg.cc/QMqSXv9P/HOMESCREEN.png)

---

## 3. User Registration & Authentication

### 3.1 Account Creation
Users must create an account to access the platform.

The registration process includes:
- Providing name and a valid email address
- Setting a secure password
- Granting location permission
- Completing initial account verification

![User Registration Screen](https://i.postimg.cc/vT2NGkKp/User-Registration-Screen.png)

---

### 3.2 Login Process
After registration, users can log in using their credentials.

Successful authentication:
- Creates a secure session
- Enables access to saved interactions
- Allows usage tracking and personalization

![Login Screen](https://i.postimg.cc/C1cgfvXL/Login-Screen.png)

---

## 4. User Interface Overview

### 4.1 Main Dashboard
The dashboard is the primary interaction space where users:
- Enter queries
- View responses
- Interact with generated insights

![Main Dashboard Layout](https://i.postimg.cc/jqhXPpMt/Main-Dashboard-Layout.png)

---

### 4.2 Input Methods
Users may interact using:
- Text-based queries
- Voice-based queries

Only one input is required per request.

---

## 5. Submitting Queries

### 5.1 Query Format
Users can ask natural language questions such as:
- Forecast-related questions
- Comparison requests
- Trend analysis queries
- Summary-based questions

No structured syntax is required.

---

### 5.2 Query Processing Flow
Once a query is submitted:
1. The request is sent to the backend system.
2. The system identifies the user’s intent.
3. Relevant data is processed.
4. A structured response is generated.
5. Results are displayed in the interface.

![Query-to-Response Flow](https://i.postimg.cc/Z5JGzWcV/Query-to-Response-Flow.png)

---

## 6. Viewing Results

### 6.1 Textual Responses
Each response includes a clear explanation of the insight derived from the data.

### 6.2 Visual Outputs
When applicable, charts or summaries are displayed alongside the explanation.

![Sample Insight Visualization](https://i.postimg.cc/cH39nWh6/Sample-Insight-Visualization.png)

---

## 7. Session Behavior

- User queries and responses may be stored for continuity.
- The interface remains responsive during processing.
- Results appear automatically once ready.

---

## 8. User Responsibilities

Users are expected to:
- Enter meaningful queries
- Avoid ambiguous language where possible
- Maintain account security

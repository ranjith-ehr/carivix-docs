# Troubleshooting & FAQ – Mini Carivix

## 1. Introduction

This document provides answers to common user questions and solutions to frequently encountered issues when using the Mini Carivix platform.

---

## 2. Frequently Asked Questions

### Q1: Why is my query taking time to respond?
**Answer:**  
Some queries require multiple processing stages. During this time, the system continues working in the background. The interface remains responsive until the response is returned.

---

### Q2: Why did I receive a generic or unclear response?
**Answer:**  
This may occur if:
- The query is ambiguous
- Required details (such as timeframe or metric) are missing

Try rephrasing the query with clearer context.

---

### Q3: Can I ask questions in any format?
**Answer:**  
Yes. The platform is designed to understand natural language. However, clearer phrasing improves accuracy.

---

### Q4: Are my previous queries saved?
**Answer:**  
User interactions may be stored to improve continuity and user experience. Availability depends on account status and session configuration.

---

## 3. Common Issues & Resolutions

### Issue: Unable to log in
**Possible Causes:**
- Incorrect credentials
- Network connectivity issues

**Resolution:**
- Verify login details
- Refresh the browser
- Try again after a short interval

---

### Issue: No visualization displayed
**Possible Causes:**
- The query does not require a visual output
- The data does not support visualization

**Resolution:**
- Review the textual explanation
- Try a different query format

---

### Issue: Voice input not working
**Possible Causes:**
- Browser permissions disabled
- Unsupported browser

**Resolution:**
- Enable microphone access
- Use a supported browser
- Switch to text input if necessary

---

## 4. Known Limitations

- Responses depend on available datasets
- Some advanced queries may require refinement
- Internet connectivity is required at all times

---

## 5. When to Seek Support

If issues persist after following this guide:
- Retry the action
- Review query clarity
- Contact platform administrators if available

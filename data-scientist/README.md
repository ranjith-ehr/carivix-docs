# Data Science Module – Mini Carivix

## Overview

This directory contains the machine learning training pipeline used to build forecasting models.

---

## Responsibilities

- Feature engineering
- Time-series modeling
- Model evaluation
- Artifact generation

---

## Directory Structure

- `training/` – Model training scripts
- `evaluation/` – Performance metrics
- `models/` – Saved model files
- `artifacts/` – Forecast outputs and insights
- `notebooks/` – Experimental exploration

---

## Outputs

- Serialized model files
- Forecast JSON outputs
- Metrics summaries

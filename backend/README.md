# Backend Service – Mini Carivix

## Overview

This directory contains the backend services responsible for:

- Intent classification
- NLP processing
- Deterministic analytics
- Forecasting
- API orchestration

The backend exposes REST endpoints used by the frontend application.

---

## Directory Structure

- `nlp/` – Natural Language Processing modules
- `models/` – Serialized machine learning models
- `artifacts/` – Model outputs and evaluation artifacts
- `requirements.txt` – Backend dependencies

---

## Responsibilities

- Receive user queries
- Classify analytical intent
- Extract structured entities
- Perform deterministic aggregation
- Generate forecast predictions
- Return structured JSON responses

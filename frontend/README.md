# Frontend Application – Mini Carivix

## Overview

This directory contains the Single Page Application (SPA) responsible for:

- User authentication
- Query submission
- Rendering insights
- Displaying visualizations

---

## Technology Stack

- React
- TypeScript
- Vite
- Tailwind CSS

---

## Responsibilities

- Handle user input
- Communicate with backend API
- Render structured responses
- Manage session state
